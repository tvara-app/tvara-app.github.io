How to see when an AI chat message was sent

Short answer: ChatGPT, Claude and Gemini record when every message was sent but do not show it. Read it from a data export, or use an extension that shows the time on hover.

ChatGPT, Claude and Gemini do not show a time on individual messages. You can scroll a conversation you have been building for three weeks and have no idea whether an answer came from Monday or from ten minutes ago — which matters the moment you ask "was this before or after the model changed?", or need to reconstruct when a decision was made.

The time exists — it is just not displayed

Every provider records when a message was created. It is stored with the conversation, used for sorting and syncing, and left out of the interface to keep it clean. So the question is not whether the timestamp exists but where you can read it.

Reading it without any tools

  • ChatGPT. Request a data export from the Data controls section of settings. The download contains a conversations.json file in which every message carries a create_time, a Unix timestamp in seconds. Accurate, complete, and no help in the moment: the export arrives by email and has to be searched by hand.
  • Claude. The data export in Claude's settings works the same way: each message in the file has a creation time.
  • Gemini. With Gemini activity saving switched on, your Google My Activity page lists each prompt with the time you sent it. It shows your prompts, not the conversation as it reads on screen.
  • Everywhere. The sidebar tells you when a conversation was last active, which dates the most recent message and nothing else.

None of these answer "when did I send this one" while you are looking at it.

What a browser can and cannot know

A browser extension sees the page, and the page is built from data the site sends. Where that data includes send times, an extension can show them for the whole history. Where it does not, no extension can recover them honestly — the most it can say is when it first saw a message on this device. A tool that shows a precise time for a message it never had a time for is guessing, and a confident wrong time is worse than none.

How Tvara shows it

Hover any message and a small time tag appears.

  • On ChatGPT you get the real send time for your whole history, read locally from the app's own state by a read-only script that makes no network request.
  • On other supported sites the browser has no historical send time, so a message is stamped when the extension first saw it and labelled first seen · this device.
  • Messages older than your install on those sites say time unknown rather than inventing one.

Timestamps are free on ChatGPT, Perplexity, DeepSeek and Grok, and part of Pro on Claude and Gemini. They are kept in Markdown and JSON exports too. See every feature · Tvara on ChatGPT
